# Bellabe Adssa — L’Aventure Scolaire v7.1

## Défis locaux immédiatement utilisables
Cette version ajoute un mode **défi à deux sur le même téléphone** :
- 2 élèves choisissent leur pseudo
- 5 ou 10 questions
- chacun répond à son tour
- score séparé
- résultat final
- fonctionnement hors ligne

Le système de profils/classes de v7.0 est conservé.

## Bluetooth
La PWA actuelle ne fait pas encore de communication téléphone-à-téléphone par Bluetooth. Le mode Bluetooth réel demandera ensuite une version Android native ou un pont natif adapté. Cette v7.1 ne prétend donc pas simuler une connexion Bluetooth.
